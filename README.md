# To-Do List CLI

A simple Command Line To-Do List made using Python.

This project is made for practicing basic Python concepts like lists, loops, conditions, user input, and basic list methods.

## Features

- Add a task
- Show all tasks
- Delete a task
- Exit the program

## Concepts Used

- `input()`
- `print()`
- Lists
- `while` loop
- `for` loop
- `if-elif-else`
- `append()`
- `pop()`
- Basic user input validation

## How to Run

1. Make sure Python is installed on your computer.

2. Download or clone this repository.

3. Open the project folder in Terminal or Command Prompt.

4. Run:

```bash
python todo.py
